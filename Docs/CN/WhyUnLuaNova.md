# 产品目标与设计原则

UnLuaNova 基于 Tencent/UnLua fork，继承其 UE 反射、覆写、容器和委托集成。产品目标是综合 slua-unreal 的使用场景、FUnLua 的对象管理经验及 Luau 的语言与工具能力，再用一致的生命周期、可观测性和验证体系做出改进。不能以项目名、代码量或用例数证明“升级版”。

1. 能力有契约：后端、版本、默认值、失败方式、平台和安全边界可查询；实验功能明确标识。
2. 所有权可解释：Env、World、UObject、协程、回调和借用内存有清晰的归属与失效规则。
3. 快路径可证明：生成绑定与反射回退行为等价，在同场景基准中测量收益和代价。
4. 工具形成闭环：源码、声明、示例、用例、构建身份和运行产物可追溯。
5. 安全可理解：可信游戏脚本与不可信扩展采用不同能力配置，沙盒开关不代替权限模型。

拟议创新包括带代际标识的 Env/World 回调句柄、生成绑定与类型声明共用签名描述、确定性网络 schema、可导出的能力清单。这些属于路线图，未作为已实现能力发布。
