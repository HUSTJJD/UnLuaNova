# Production Deployment and Operations

For teams integrating UnLuaNova into a shipping project. Release criteria live in
[Release Readiness](Release_Readiness.md); API contracts in [API Stability](API_Stability.md).

## 1. Pre-release checks (in order)

```powershell
python -B Tools/AuditRepository.py
python -B Tools/CheckPromotion.py
python -B Tools/ValidateProvenance.py --require-current
.\Tools\RunDevelopmentTests.ps1 -NetMatrix          # per backend: 8 Legacy scenarios + 4 variants (independent groups)
.\Tools\RunTests.ps1                                # complete Release
```

`CheckPromotion.py` is read-only and never changes state for you. Nothing ships while any
item is unmet.

## 2. Licence scope

This repository (UnLuaNova) is **MIT** (`LICENSE`); inherited and third-party components
keep their own licences, listed in `LICENSE-THIRD-PARTY.md`. The outer `UEAbilityKit`
workspace is a **separate project** with its own licence and is explicitly outside the
scope of this page and of the release gate.

`Tools/GenerateNotices.py` remains available as a standalone manifest generator (a
reproducible `NOTICES.txt` from facts already in the repository), but by the 2026-11-13
maintainer decision it is **not a Release stage** and requires no `Docs/legal/`
external evidence files.

## 3. Security boundaries (do not enable defaults casually)

| Switch | Default | Risk |
|---|---|---|
| `bDataDrivenBinding` | `False` | When on, objects matching a mapping/component get a script bound without their knowledge |
| `bDeclaredNetworking` | `True` | Master switch; off means no dynamic UFunction construction and no replicated-field registration |
| `bRequireRpcAuthorization` | `False` | Enabled without an installed handler is a config error; the policy fails closed |
| `bAllowHotReloadSchemaChange` | `False` | Allows layout changes on reload; every peer must negotiate |
| `lua.sandbox` | off | Path checks are not an OS-level sandbox; untrusted scripts need a capability policy |
| `lua.codegen.enabled` | 0 | Upstream allocates executable pages; the host does not take over W^X |

Query with `UnLuaNova.HasFeature('<name>')`, e.g. `'declarednetworking'`, `'sandbox'`.
Install an RPC authorization handler in C++ via
`FUnLuaNovaNetPolicy::SetAuthorizationHandler`; the engine's owner check is always in
force and this policy is an **additional application-layer** check.

## 4. Diagnostics and observability

| Capability | Entry | Note |
|---|---|---|
| CPU profiler | `lua.profiler` -> Unreal Insights | plain Lua pairs call/return for exact self time; Luau uses safe-point attribution, not exact numbers |
| Breakpoints | `lua.dap` | attach only, no launch; 18 unsupported DAP commands give concrete reasons |
| Headless debug | `lua.dbg` | Different deployment scope from the editor DAP adapter |
| Memory | `lua.memstats` / `Saved/ReleaseTests/*/metadata/memory` | Nine cases including a retained-reference control |
| Dead loops | `lua.maxsafepoints` / watchdog | `DeadLoopCheck` defaults to 0 (off) |
| Coverage | `lua.coverage` | **Luau only**; plain Lua reports unsupported |
| Net policy log | `FUnLuaNovaNetPolicy::SetDeniedLogger` | Every denial carries `ELuaNetPolicyResult`, reason, object, schemas and generation |

## 5. Packaging and platforms

- Verified baseline: **UE 5.8.3 / Win64**; UE 6.0 has adaptation branches but no passing
  complete Release. See the [support matrix](Engine_Support.md).
- A first UE 6.0 package triggers a FULL COOK and full shader compile; one stage can
  exceed the default 60 minutes: set `$env:UNLUANOVA_RELEASE_TIMEOUT_MINUTES = 180`
  before `RunTests.ps1`.
- `.uplugin` `PlatformAllowList` lists **permitted compile targets**, not accepted platforms.
- Shipping is a packaging gate, not Shipping runtime certification; `lua.codegen` has no
  run acceptance on arm64 / Shipping.

## 6. Upgrade and rollback

1. Save the current `Saved/ReleaseTests/baseline/release-summary.json` and its commit.
2. After an upgrade, never overwrite new defaults with a whole project-side ini; keep diffs only.
3. Generated sources in `Source/UnLuaNova/Generated/Backends/<Backend>/` are isolated per
   backend and must not be committed.
4. Roll back by git tag; the 22 existing tags are inherited from upstream UnLua, not this
   plugin's releases.
5. Release claims are generated by `Tools/UpdateReleaseStatus.py`; never hand-edit the
   markers on the eight pages.
